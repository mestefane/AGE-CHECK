# Age Check 💗

Um verificador de idade simples e interativo, feito com HTML, CSS e JavaScript puro. O usuário informa o ano de nascimento e o sexo, e o sistema calcula a idade, exibe a faixa etária (criança, jovem, adulto ou idoso) e mostra uma ilustração correspondente.

## Acesse o projeto

**Site funcionando:** https://mestefane.github.io/AGE-CHECK/

## Preview

![Preview do Age Check](preview.png)

## Funcionalidades

- Cálculo automático da idade a partir do ano de nascimento
- Classificação por faixa etária: criança, jovem, adulto ou idoso
- Ilustração personalizada de acordo com o sexo e a faixa etária
- Layout responsivo, adaptado para desktop e celular
- Validação de dados (impede envio de campos vazios ou anos inválidos)

## Tecnologias usadas

- **HTML5** — estrutura da página
- **CSS3** — estilização, gradientes, animações
- **JavaScript** — lógica de cálculo de idade e manipulação do DOM

## Como rodar localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/mestefane/AGE-CHECK.git
   ```
2. Entre na pasta do projeto:
   ```bash
   cd AGE-CHECK
   ```
3. Abra o arquivo `.html` principal diretamente no navegador, ou use a extensão **Live Server** do VS Code para uma experiência mais próxima do ambiente de desenvolvimento.
